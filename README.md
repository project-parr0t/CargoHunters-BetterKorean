# CargoHunters-BetterKorean
Cargo Hunters 스팀 게임 AI 기반 한국어 오역 검수 패치

## 이게 뭐죠?
해당 깃허브 레포지토리는 parr0t AI 번역 프레임워크를 통해 [Cargo Hunters](https://store.steampowered.com/app/4197990/Cargo_Hunters/)의 한국어 언어 패치를 교정한 프로젝트입니다.
parr0t은 조금 더 부드럽고 오역이 적은 AI 기반 게임 번역 프레임워크 코어입니다.

## 바이브 코딩인가요?
네. 게임을 즐기는데 번역까지 일일히 다 하고 싶진 않았습니다.

## 무엇으로 번역했나요?
ChatGPT Codex를 기반으로 ChatGPT 6.1 Luna 서브에이전트를 통해 번역하였으며, ChatGPT 6.1 Sol을 통해 스크립트를 검수하였습니다.

세이프가드로 인해 번역이 중단된 내용은 Deepseek 4.1 Flash와 DeepSeek 4.1 Pro를 통해 1차 폴백으로 번역되었습니다.

## 어떻게 설치하나요?
1. 게임을 완전히 종료합니다.
2. [Releases](https://github.com/project-parr0t/CargoHunters-BetterKorean/releases/latest)에서 최신 한국어 패치 ZIP을 다운로드합니다.
3. ZIP의 내용물을 한 폴더에 모두 압축 해제합니다.
4. `Install-Korean-Patch.bat`을 실행하고 화면의 안내를 따릅니다.

설치기가 Steam에서 게임 위치를 자동으로 찾습니다. 찾지 못하는 경우 게임 폴더 경로를 직접 입력하거나 탐색기에서 끌어 놓으면 됩니다.

패치 업데이트와 제거도 같은 `Install-Korean-Patch.bat`에서 진행할 수 있습니다.

## 코드도 공개되어 있나요?
네. 저장소에는 실제 배포본과 같은 설치기, 패치 전용 브리지 소스, 한국어 번역 데이터와 검증용 매니페스트가 들어있습니다.

parr0t 번역 SDK와 작업용 데이터는 포함되어 있지 않습니다. 공식 BepInEx 런타임은 저장소에 중복해서 올리지 않고 Releases의 설치 ZIP에만 포함하며, 사용한 버전과 해시는 `artifacts` 폴더에서 확인할 수 있습니다.

## 게임이 안 켜져요 / 게임이 튕겨요!
원본 언어에서 크래시가 발생하는 것이 아니라면 패치 자체의 오류입니다.
이슈를 열고 오류 내용과 상황을 알려주세요, 제 든든한 코덱스 부관이 해결해줄겁니다.

## 기여를 받나요?
물론이죠! 더 나은 번역이 있다면 기여해주세요. 인간 담당자와 ChatGPT 사수와 함께 추가 번역을 검토 후, 반영합니다. 

## 번역되는 게임들에 기준이 있나요?
조직 주인장이 하고 싶은 게임을 번역합니다.

큰 기준은 없으며, 하고 싶은것 위주로 진행되고 있습니다.
